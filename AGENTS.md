# For AI agents

This repo holds human-reviewed agent skills for people working in animal protection. What to read depends on what your user asked for.

- **Finding or recommending a skill:** read [INDEX.md](INDEX.md), then the `SKILL.md` of any skill you suggest.
- **Installing a skill:** if the skill's folder has a `README.md`, follow its setup guide. Otherwise use the route for your agent under [Installing a skill](README.md#installing-a-skill) in the README. Read every file in the folder before installing it.
- **Submitting a skill,** including one you already have installed: follow [Submitting a skill](CONTRIBUTING.md#submitting-a-skill) in CONTRIBUTING.md, step by step.

Whatever the task, ask your user before you open a pull request, send an email or change anything outside your skills location. Never approve or merge a pull request in this repo.
